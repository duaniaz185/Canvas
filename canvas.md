This interactive drawing app is built with HTML5 Canvas, CSS, and JavaScript. It lets users draw using mouse events, change brush colors and sizes, and clear the canvas. The project features a modern responsive design with smooth drawing effects, showcasing JavaScript event handling and canvas-based graphics for dynamic web applications.
